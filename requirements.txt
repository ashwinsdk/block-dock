Step 1: cd block-dock
Step 2: cd block-dock
Step 3: npm install
Step 4: cd ..
Step 5: cd backend
Step 6:npm install
Step 7: npm install --save-dev hardhat
Step 8:npx hardhat 
Step 9: npx hardhat compile
Step 10: In another command prompt, run the following command
Step 11: npx hardhat node and then use another command prompt for running other commands
Step 12: npx hardhat run scripts/deploy-localhost.js --network localhost
     Make sure that the .env file consists of the following:
     LOCALHOST_RPC_URL=http://127.0.0.1:8545
    LOCALHOST_PRIVATE_KEY=0xdf57089febbacf7ba0bc227dafbffa9fc08a93fdc68e1e42411a14efcf23656e
    SEPOLIA_RPC_URL=your rpc url
    SEPOLIA_PRIVATE_KEY=your private key
    And make sure that .env file is added to .gitignore and is in scripts folder ,for now dont worry about sepolia
Step 13: After the deployment is successful , you will receive the contract address
Step 14: Copy the contract address and paste it in every js file in the frontend folder
Step 15: In the frontend folder, run the following command
Step 16: npm install path-browserify
Step 17: npm install os-browserify
Step 18: Then give npm start
Step 19: The frontend will be running on http://localhost:3000
Step 20: You can now interact with the frontend


Use 3 different accounts :one for Admin,one for AdminHead and another for User.
The address from which you deploy the contract is the Admin address.You will get it in npx hardhat node.
